# Persian-First Code

# تعریف یک تابع
کار فیبو(n):
    اگه n <= 1:
        بده n
    وگرنه:
        بده فیبو(n - 1) + فیبو(n - 2)

برای هر i توی محدوده(10):
    بنویس(فیبو(i))

# Why Azravibe?

زبان‌های برنامه‌نویسی معمولاً با کلمات انگلیسی طراحی می‌شوند. آذرویب با کلمات فارسی طراحی شده است — و محیط توسعه‌اش هم پشتیبانی کامل راست به چپ (RTL) دارد.

Instead of if / def / while, you write اگه / کار / تا وقتی — a familiar, Python-like syntax using natural Persian keywords, with full English aliases for bilingual developers.
