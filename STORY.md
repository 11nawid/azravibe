# Why I Built Azravibe

Azravibe started as an experiment.

I'm a developer from Afghanistan, and while working on other projects, I became curious about something I had never built before:

**How does a programming language actually work?**

Instead of only reading about compilers, parsers, syntax, and interpreters, I decided to try building one myself.

That experiment became **Azravibe**.

But I wanted to make it a little different.

As a Persian-speaking developer, I wondered:

**What if programming keywords were written in Persian?**

What if instead of writing something like:

```text
if (condition) {
    ...
}
```

you could express the same idea using Persian syntax?

And if the language was designed for Persian, why shouldn't the development environment support **RTL** properly too?

So I started experimenting with Persian/Farsi syntax and eventually built an RTL-focused IDE alongside the language.

### It wasn't supposed to become a huge project

Azravibe isn't my main project, and I'm not trying to pretend that it is a finished programming ecosystem.

I built it because I wanted to learn.

I wanted to understand how languages are designed, how source code becomes something a computer can execute, how compilers work, how parsers work, and what it actually takes to build developer tooling.

Along the way, the small experiment became a real, working language that can already be used to build CLI programs.

So I decided:

**Why not open-source it?**

Maybe someone will find it interesting.

Maybe a student will learn something from the compiler.

Maybe a Persian-speaking developer will enjoy writing a few programs in it.

Maybe another programmer will look at the source code and think:

*"I want to build a language too."*

And honestly, that would be enough.

### Where Azravibe goes from here

Azravibe is still experimental and has a lot of room to grow.

There are many things it doesn't support yet, and I may continue improving it whenever I have time or whenever I get a new idea.

There is no promise that it will become the next major programming language.

That's not really the point.

**The point was to learn by building something that seemed difficult.**

And now I'm sharing what I built.

If you're interested, try it, break it, study it, contribute to it, or simply explore how it works.

Maybe you'll learn something from it too.
