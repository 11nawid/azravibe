# Azravibe Keyword Reference

Every Azravibe keyword has a Persian/Farsi form and an English alias. Both forms work identically.

---

## Control Flow

| Persian | English | Description |
|---|---|---|
| `اگه` | `if` | Conditional branch |
| `وگرنه اگه` | `elif` | Else-if branch |
| `وگرنه` | `else` | Else branch |

## Comma Usage

Both Latin comma (`,`) and Persian/Arabic comma (`،`) are accepted as separators everywhere in the language:

```azr
# Both of these are valid:
کار جمع(a, b):       # Latin comma
کار جمع(a، b):       # Persian comma

اعداد = [1، 2، 3]    # Persian comma
اعداد = [1, 2, 3]    # Latin comma
```

---

## String Interpolation

Strings containing `{` and `}` automatically interpolate expressions:

```azr
نام = "آذرویب"
بنویس("سلام {نام}")       # سلام آذرویب
بنویس("{2 + 2}")          # 4
```

Escape literal braces with `{{` and `}}`:

```azr
بنویس("آکولاد {{نمونه}}")  # آکولاد {نمونه}
```
